# TBAH (TaskBar Auto Hider) 🚀

[English](#english) | [Русский](#русский)

---

## English

A lightweight Windows utility that automatically hides the taskbar. The taskbar only appears when you press the **Win** key and instantly hides when you switch to another window (browser, game, or desktop). 

The program runs entirely in the background, takes up no screen space, and does not open any console windows.

### ✨ Features
* 🖥️ **Full Automation** — Hides the taskbar immediately upon Windows startup.
* ⌨️ **On-the-Fly Control** — Quickly toggle the hiding mode on/off using a hotkey.
* ⚙️ **GUI Settings** — A convenient built-in menu to change delays and control keys.
* 📦 **Startup Integration** — Automatically registers itself in the Windows registry on the first launch.
* 🔔 **System Notifications** — Notifies you of a successful background launch via standard Windows toast notifications.

### ⌨️ Controls (Default Hotkeys)
* `Win` — Temporarily show the taskbar (Start Menu).
* `Win + Ctrl + X` — **Toggle On / Off** (puts the program to sleep and restores the standard taskbar).
* `Win + Ctrl + Shift + X` — **Open Settings Menu** (opens a graphical window to change hotkeys and delays).

> 💡 *All custom keys and parameters are automatically saved to the `config.ini` file.*

### 🚀 Installation Guide
1. Download the compiled **`TBAH.exe`** from the **Releases** tab on the right side of this page.
2. Move the downloaded file to any permanent folder on your PC.
3. Launch the program with a double-click. A notification will appear in the corner of your screen — from this moment on, the utility runs in the background and is added to Windows Startup.

## Русский

Легковесная утилита для автоматического скрытия панели задач Windows. Панель появляется только при нажатии клавиши **Win** и мгновенно скрывается, когда вы переключаетесь на другое окно (браузер, игру или рабочий стол).

Программа работает полностью в фоновом режиме, не занимает место на экране и не открывает окон консоли.

### ✨ Основные возможности
* 🖥️ **Полная автоматизация** — скрывает панель задач сразу при старте системы.
* ⌨️ **Управление на лету** — быстрое включение и выключение режима скрытия с помощью хоткея.
* ⚙️ **Графические настройки** — удобное встроенное меню для изменения задержек и клавиш управления.
* 📦 **Автозагрузка** — программа сама аккуратно прописывает себя в реестр Windows при первом запуске.
* 🔔 **Уведомления** — сообщает об успешном фоновом запуске через стандартные системные уведомления Windows.

### ⌨️ Управление (Горячие клавиши по умолчанию)
* `Win` — временно показать панель задач (меню Пуск).
* `Win + Ctrl + X` — **Включить / Выключить** скрытие (переводит программу в режим сна и возвращает стандартный таскбар).
* `Win + Ctrl + Shift + X` — **Открыть меню настроек** (появится графическое окно, где можно изменить хоткеи и задержки).

> 💡 *Все измененные клавиши и параметры автоматически сохраняются в файл `config.ini`.*

### 🚀 Инструкция по установке
1. Скачайте готовый файл **`TBAH.exe`** из вкладки **Releases** справа на странице этого репозитория.
2. Перенесите скачанный файл в любую удобную постоянную папку на компьютере.
3. Запустите программу один раз двойным кликом. В углу экрана появится уведомление о запуске — с этого момента утилита работает в фоне и добавлена в автозагрузку Windows.
